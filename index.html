Signal Pipeline

PHASE 01 · REAL-TIME SENSING
01

Acquire

MAX30102 PPG sampled over I2C + AD8232 ECG read via Analog Pin A0. Raw telemetry is framed into JSON packets.

02

Filter

Arduino DSP zero-centers the signal baseline, with auto-reset pulse memory when the finger lifts.

03

Telemetry

Dual output: 100 Hz real-time Web Serial / SPP stream + Automatic 1 Hz batched Firebase Database recording.
